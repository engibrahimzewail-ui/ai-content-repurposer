# AI Content Repurposer

Micro-SaaS to convert articles and text into Twitter threads, LinkedIn posts, and newsletter summaries using AI.

## Quick Start

1. Install dependencies:
```bash
pip install -r requirements.txt
```

2. Run the application:
```bash
streamlit run app.py
```

3. Enter your OpenAI API Key in the sidebar, input an article URL or text, and generate content instantly!

## Deployment
Deploy for free in 2 minutes on [Streamlit Community Cloud](https://streamlit.io/cloud) or [Hugging Face Spaces](https://huggingface.co/spaces).
